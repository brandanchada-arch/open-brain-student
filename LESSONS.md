# Lessons (this project)

- **Some edge functions exist only on Supabase, not in this repo** (daily-quiz, gap-questions, capture-voice, planner-bot, bc-*). Before changing a table, run `npx supabase functions list` and `npx supabase functions download <name> --workdir <scratch folder> --use-api` to find every reader. (2026-10-22)
- **The deployed copy can differ from the repo** (open-brain-mcp accepted `?key=` live but not in git). Diff the download against the repo before redeploying. (2026-10-22)
- **Querying `information_schema.triggers` prints the Database Webhook's service key** (it is written into the trigger). Don't select `action_statement` for webhook triggers. (2026-10-22)
- **A RESTRICTIVE RLS policy** (`as restrictive for select ... using (archived_at is null)`) hides rows from the live web app instantly, without redeploying it. The service role still sees everything. (2026-10-22)
- **Many files here have Windows (CRLF) line endings**, so string-matching edits with `\n` in a script fail silently and can wreck the file. Use the editor tool. (2026-10-22)

- A function deployed with --no-verify-jwt is open to the whole internet: it must check the caller itself. telegram-bot ran for weeks with no check. (2026-11-03)
- In a script that deploys then tests, stop at the first failure. A failed deploy meant the test ran against the old, unlocked bot. (2026-11-03)
- **Cloud sessions run on Linux, so "all tests pass" there doesn't mean they pass on this PC.** 34 tests failed here at first. `await import(path)`, `URL.pathname` and symlinks only worked on Linux. Use `pathToFileURL`, `fileURLToPath` and `symlinkSync(..., 'junction')`. (2026-11-03)
- **`bc_brain_status()` and other locked functions fail under `db query --read-only`** with "permission denied". That's the lock working, not a bug. (2026-11-03)
- **A report's claim about what code does still needs checking against the code.** The rehearsal said a same-week digest re-run updates the entry, but the title holds the dates. Our real run stopped earlier ("only 4 thoughts"), so a 200 alone proved only that it got past the token check: read the reply too. (2026-11-03)
- **Ctrl+V at a hidden PowerShell prompt can enter one control character instead of pasting.** A single `*` means the key didn't go in, and every check after it fails. Read keys from a file or the clipboard, and validate them. (2026-11-03)
- **The `enrich-thought` webhook sends its token with no "Bearer".** You can learn a trigger's header form safely with regex yes/no queries that never return the definition: `supabase/sql/checks/enrich-webhook-check.sql`. (2026-11-04)
- **A scan for private names before each commit catches what a rule alone doesn't.** A channel id nearly went into `NEEDS-BRANDAN.md` in this public repo while writing a helpful test link. (2026-11-04)
- **New Library doc types can leak into older readers.** The Sunday condenser reads every recent Library row, so outside video titles would have reached brain page proposals. When adding a doc type, check every reader of `library`. (2026-11-04)
- **When a prompt joins several sources and then trims to a total, the later source gets starved.** One fixture row of each kind can't show it. Test with realistic volume and give each source its own room. (2026-11-04)
- **Ask for the actual PASS/FAIL lines.** "done pass" hid four failed key checks until the output was pasted later. (2026-11-03)
- **A test that skips on your computer can hide a break.** `master` added `--model sonnet` to the session log worker, but two tests still expected the old flags. They only ran on Linux, so nobody saw it until the overnight work made them run on Windows. (2026-11-05)
